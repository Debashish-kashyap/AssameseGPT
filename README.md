# AssameseGPT — Assamese AI. Built From Scratch.

AssameseGPT is a production-grade conversational AI platform powered by custom Assamese language models, designed to deliver a modern, fluid ChatGPT/Claude-style experience with native Assamese language understanding, multilingual fluency, and rich code formatting.

---

## ✨ Features

- 🧠 **Native Assamese AI**: Tailored for authentic Assamese grammar, vocabulary, idioms, and cultural heritage.
- 🌐 **Multilingual & English Fluency**: Seamlessly switches between Assamese, English, and mixed queries.
- ⚡ **Token Streaming**: Real-time response generation with pause/stop generation controls.
- 💻 **Syntax Highlighting**: Supports syntax highlighting for Python, JavaScript, TypeScript, Java, C++, and more with one-click code copying.
- 📑 **Rich Markdown Support**: Full GFM support including tables, lists, and quotes.
- 🗂 **ChatGPT-Style Sidebar**: Auto-collapsible sidebar with conversation search, date-based grouping (*Pinned, Today, Yesterday, Previous 7 Days*), rename, and delete actions.
- 🎨 **Adaptive Themes**: Refined Dark and Light mode powered by `next-themes`.
- ⚙️ **Model Switching & Customization**: Configure between AssameseGPT 74M, 17M, and Research v2 models, tweak temperature, and adjust system instructions.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Markdown & Syntax Highlighting**: React-Markdown, Remark-GFM, React-Syntax-Highlighter
- **Theme**: next-themes

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Debashish-kashyap/AssameseGPT.git
cd AssameseGPT
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```
